    無人機架構盤點

    目前的理解來看，無人機可以拆成

    1. flight stack : 負責位置、控制、導航，大致簡稱飛控
    2. middleware : 通訊連接硬體跟外部系統
    3. Hardware/OS : 幾乎沒有包OS，在MCU上面跑

    常見的 Flight Stack 幾乎都是 PX4和 Ardupilot 架構 下面用PX4為範例，middleware就是 mavlink

    跟一般的 IoT 不太一樣，不是那種會飛的超級router而已 是以飛控為中心，用協議串聯不同的週邊設備
