    LCGOracle 智能合約+LCG，定義合約號並deploy contract with LCG LCG formula: Xn+1​=(aXn​+c) mod mX_{n+1}​=(aXn​+c) \text{ mod } mXn+1​​=(aXn​+c) mod m

    基本上就是拿LCG的m, c, n, seed 去遠端呼叫合約函數計算LCG的值最後返回狀態

    TripleXOROracle

    ciphertext = primeFromLcg XOR conversationTime XOR plaintext so primeFromLcg = ciphertext XOR conversationTime XOR plaintext

    ChatLogic

    1. Seed 生成: 拿電腦名稱做sha256當作hash seed
    1. LCG prime 生成

    把seeds拿去不斷sha256之後當成int、檢查是不是質數直到拿到三個數字 所以目前為止LCG的幾項輸入都是已知且固定的

    1. set enc method
    modeencryption

    safeRSA

    去看輸出的 chatlog.json，一共7則LCG-XOR跟2個RSA，[ENCRYPTED] 部分沒有明文的應該就是我們要的東西

    solution

    1. 從前面TripleXOROracle可知LCGstate = ciphertext XOR time XOR plaintext_word
    2. 破LCG參數 — 連狀態關係：vi+1=M∗vi+C(modN)v_{i+1} = M*v_i + C (mod N)vi+1​=M∗vi​+C(modN) - 差分：di=vi+1−vid_i = v_{i+1} - v_idi​=vi+1​−vi​ - 代數：di+2=M∗di+1→di+2∗di−di+12≡0(modN)d_{i+2} = M*d_{i+1} → d_{i+2}*d_i - d_{i+1}^2 ≡ 0 (mod N)di+2​=M∗di+1​→di+2​∗di​−di+12​≡0(modN) - gcd全式 → N（模數） - 反演：M=(v2−v1)/(v1−v0)modNM = (v_2-v_1) / (v_1-v_0) mod NM=(v2​−v1​)/(v1​−v0​)modN - 求C：C=v1−M∗v0modNC = v_1 - M*v_0 mod NC=v1​−M∗v0​modN
    3. 續推迭代 — 用M,C,N重複迭代，蒐集256位質數8個
    4. RSA破解 — n = 質數乘積，φ=∏(p−1)，d=e−1modφφ = ∏(p-1)，d = e^{-1} mod φφ=∏(p−1)，d=e−1modφ，解密
